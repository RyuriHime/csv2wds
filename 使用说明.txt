============================================================
 WDS 转谱器 —— 官方谱面 CSV → .wdschart
============================================================

【最简用法】
  1) 双击 WDS转谱器.exe
  2) 把 .csv 拖进窗口(或点「浏览...」选文件)
  3) 手动填写 BPM
  4) 点「开始转谱」
  → 在同目录生成同名的 .wdschart


【更省事】
  直接把 .csv 拖到 WDS转谱器.exe 上,窗口会自动弹出。
  注意:拖进来也仍然要自己填 BPM,程序不会替你猜。


【一首歌一个文件夹的话】
  点「整个文件夹批量转...」,选那个文件夹,
  里面所有 .csv 会各自转成同名的 .wdschart。
  批量的所有文件会用同一个 BPM,所以只适合同一个 BPM 的一组谱面。


【为什么必须手动填 BPM】
  CSV 里只有「秒」,没有 BPM,时间轴完全靠 BPM 换算。
  BPM 填错整首谱面都会错位,也没有可靠的自动推断办法,
  所以本工具**不做任何猜测**,留空就拒绝转换。


【生成出来的谱面】
  WDSCHART 5 / TPQ 480 / 单 BPM(4/4 拍)
  音符数 = CSV 行数 − noteType=900 的行数
      900 是编辑器目前还没实现的分裂线数据,编辑器自己导入 CSV 时
      同样会丢掉。想保留就勾上「保留 noteType=900 的行」。
  长条里的星星:
      chart 里写成  N <id> <tick> <tick> <30|31> <lane> <宽> 0 0 <所属长条id>
      普通长条(100/101)里的星星是 30,滑键长条(110/111)里的星星是 31。
      CSV 里星星可以写 30/31,也可以写 40;写 40 时本工具会按它落在
      哪条长条里自动换成 30 或 31,并把最后一格填成那条长条的 id。
  CONCURRENT(并发线)会按同样的规则自动算出来。
  NOTES 按起始 tick 升序排列,同一 tick 内保持 CSV 原有顺序。


【如果打开后看不到音符】
  编辑器是按「项目」工作的。请把生成的 .wdschart 放进目标文件夹后,
  在编辑器里把它加入项目,或者自己写一个 .wdsproject,格式如下:

      WDSPROJECT 2
      MUSIC <音频文件的完整路径>
      CHART_DELAY_MS 0
      ACTIVE_CHART 0
      CHART 你的谱面.wdschart
      END

  然后打开这个 .wdsproject。只把 .wdschart 拖进编辑器,有时只会新建一个
  没有音频的空项目,看上去就像"什么都没显示"。


【注意事项】
  · BPM 一定要填对。
  · 生成的文件会覆盖同目录下的同名 .wdschart。
  · 时间是吸附到 1/24 拍网格上的(TPQ 480 = 20 tick 一格),
    这正好能表示 16 分、24 分、32 分时值。
  · 需要 Windows 自带的 .NET Framework 4(Win7 及以上都有,
    不用装 Python 或其它运行库)。
  · 谱面文件是 UTF-8(无 BOM)+ LF 换行。


【命令行用法(批处理/脚本)】
  WDS转谱器.exe "谱面.csv" --bpm 194
  WDS转谱器.exe "谱面.csv" --bpm 194 --out "输出.wdschart"
  WDS转谱器.exe "谱面.csv" --bpm 194 --keep-900
  WDS转谱器.exe "谱面.csv" --bpm 194 --quiet      不弹窗,直接转

  不带 --bpm 会直接报错退出。
